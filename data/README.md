# Dataset notes

`simulated_symptoms.csv` contains 15 hand-written illustrative records with seven binary symptom features and a `disease` label. These are synthetic examples for a coding and evaluation exercise; they are not patient records, not a medically reviewed dataset, and not suitable for diagnosis or clinical conclusions.

The deliberately small dataset contains repeated rows, a pattern with conflicting labels, and labels with only one example. The project reports those issues rather than concealing them.
